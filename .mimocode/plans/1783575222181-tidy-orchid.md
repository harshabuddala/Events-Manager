# Landing Page Integration Plan

## Goal
Convert the standalone `edunura-landing-page/` Vite+React app into Next.js components, replacing the existing public registration page at `/public/register/[eventId]`.

## Approach
Server Component fetches event data from Prisma → passes serialized props to `'use client'` wrapper → renders 18 section components with dynamic data.

## Step 1: Install Dependencies
```bash
npm install canvas-confetti
npm install -D @types/canvas-confetti
```

## Step 2: Copy Images
`edunura-landing-page/imges/*` → `public/landing/highlights/` (9 carnival photos)

## Step 3: Create Directory Structure
```
app/public/register/[eventId]/
  page.tsx                    # Server Component (rewrite)
  PublicLandingPage.tsx       # 'use client' wrapper
  landing/
    types.ts                  # LandingEventData interface
    hooks/
      useCountdown.ts         # Copy from landing page
      useScrollAnimation.ts   # Copy from landing page
    components/
      ScrollProgress.tsx
      AnimatedSection.tsx
      Navbar.tsx
      Hero.tsx
      HowItWorks.tsx
      TrustStrip.tsx
      ActivityZones.tsx
      CTABanner.tsx
      ParentFunZone.tsx
      EventDetails.tsx
      MapSection.tsx
      AboutEduNura.tsx
      CarnivalHighlights.tsx
      RegistrationForm.tsx    # Rewired to use API routes
      FAQ.tsx
      ShareStrip.tsx
      Footer.tsx
      WhatsAppBubble.tsx
```

## Step 4: Add Baloo 2 Font
In `app/layout.tsx`, add `Baloo_2` from `next/font/google` with `--font-baloo2` variable.

## Step 5: Update globals.css
Add `@theme` block for:
- Brand colors: `brand-primary (#0B1F4D)`, `brand-accent (#F5730B)`, `brand-bg (#FAFAF7)`
- Display font: `--font-display: var(--font-baloo2)`
- Animations: `bounce-in`, `pulse-scale`
- Utility: `hide-scrollbar`

## Step 6: Convert Components
Each component gets `'use client'` + props for dynamic data:

| Component | Dynamic Props |
|-----------|--------------|
| Hero | eventName, eventDate, venueName, venueDetail |
| Navbar | fee |
| HowItWorks | fee, eventDate |
| EventDetails | event (full LandingEventData) |
| MapSection | venueAddress |
| CTABanner | fee |
| ShareStrip | eventName, eventDate |
| CarnivalHighlights | (string image paths instead of Vite imports) |
| RegistrationForm | event (full LandingEventData) |
| Others | Static content, no changes |

## Step 7: Rewrite RegistrationForm
- Keep landing page visual design (multi-kid cards, orange styling, confetti)
- For paid events: loop through kids → create-order → Razorpay checkout → verify-payment
- For free events: use POST /api/public/events/[id]/register
- Map form fields: `whatsappNumber` → `phoneNumber`, `class` → `grade`

## Step 8: Create PublicLandingPage.tsx
Client wrapper that receives `LandingEventData` and renders all 18 sections with props.

## Step 9: Rewrite page.tsx
Server component with Prisma query, serialize event data, pass to PublicLandingPage.

## Step 10: Delete Old Files
- `public-register.css` — replaced by Tailwind
- Old `RegisterForm.tsx` — replaced by landing RegistrationForm

## Step 11: CSP Update
Add `https://cdn.pixabay.com` to `connect-src` in middleware if audio CDN is blocked.

## Verification
1. `npm run build` — no errors
2. Visit `/public/register/[eventId]` — landing page renders with event data
3. Test paid flow: create-order → Razorpay → verify-payment → success + confetti
4. Test free flow: direct registration without payment
5. Test responsive: mobile sticky CTA, desktop layout
6. Test animations: scroll-triggered fade-ins, countdown timer
