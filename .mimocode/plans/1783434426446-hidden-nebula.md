# Auto-Send WhatsApp on Registration — Plan

## What Changed

Add automatic WhatsApp message on registration with ID card image and customizable message.

---

## Requirements

1. **Auto-send on registration** — When student is registered (API or public form), send WhatsApp automatically
2. **ID card image** — Generate actual ID card image (not placeholder) and send as WhatsApp image
3. **Customizable message** — Admin can configure message template in Settings → WhatsApp

---

## Files to Modify

### 1. WhatsApp Settings — `app/settings/whatsapp/page.tsx`

Add fields for customizable message template:
```
Registration Message Template:
  Hi {parentName}, your child {studentName} has been registered for {eventName}.

  Roll Number: {rollNumber}
  Event Date: {eventDate}

  Please find your ID card below. Present it at the event entry.
```

Variables available: `{parentName}`, `{studentName}`, `{eventName}`, `{rollNumber}`, `{eventDate}`, `{communityName}`

### 2. Database — `prisma/schema.prisma`

Add `registrationMessageTemplate` field to `WhatsAppConfig` model:
```prisma
model WhatsAppConfig {
  // ... existing fields ...
  registrationMessageTemplate String?
  autoSendOnRegistration      Boolean @default(false)
}
```

### 3. Settings API — `app/api/settings/whatsapp/route.ts`

- GET returns `registrationMessageTemplate` and `autoSendOnRegistration`
- POST saves these fields

### 4. ID Card Generator — `lib/id-card.ts` (NEW)

Generate ID card image using canvas (node-canvas or sharp):
- Takes student data (name, rollNumber, grade, eventName, qrToken)
- Generates PNG image with Edunura branding
- Returns Buffer

### 5. WhatsApp Utility — `lib/whatsapp.ts`

Update `sendRegistrationMessage` to:
- Use customizable template instead of hardcoded message
- Accept and send ID card image instead of QR code

Add `sendIdCardMessage` function that:
- Generates ID card image
- Uploads to WhatsApp
- Sends to parent with custom message

### 6. Registration API — `app/api/v1/registrations/route.ts`

After creating registration:
- Check if WhatsApp config has `autoSendOnRegistration = true`
- If yes and phone number exists, auto-send ID card message
- Non-blocking (fire-and-forget, don't fail registration if WhatsApp fails)

### 7. Public Registration API — `app/api/public/events/[id]/register/route.ts`

Same auto-send logic after registration.

### 8. Registration Page — `app/api/registrations/route.ts`

Same auto-send logic for admin-created registrations.
